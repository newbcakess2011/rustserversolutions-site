Preflight Checklist

To ensure a swift and smooth server build, please review this checklist and gather the necessary information before opening a ticket with us.

1. Hardware & Hosting Access

Purchased Host

You must have an active game server purchased from a hosting provider (like Physgun). We do not provide hardware.

Panel Credentials / Subuser Access

We will need access to your game panel (Pterodactyl, TCAdmin, etc.). This can be your login, or a "Subuser" account created with full permissions.

2. Server Identity

Exact Server Name & Description

Know exactly what you want your server to be called in the Rust browser, and the short description that appears when players click on it.

Header Image & URL

Have a 512x256 pixel header image uploaded somewhere (like Imgur) for your server banner. Have your Discord invite link ready.

3. Schedules & Management

Wipe Schedule

Decide on your Map and Blueprint wipe frequency (Weekly, Bi-weekly, Monthly). Let us know the exact day of the week and time you prefer.

Staff Roster (Steam64 IDs)

Have a list of the 17-digit Steam64 IDs for all Owners, Admins, and Moderators who need permissions assigned.

4. For Modded Servers (If Applicable)

Plugin Wishlist

A comprehensive list of mechanics, features, or specific plugins you want installed (e.g., Kits, TP, Loot+).

VIP Tier Definitions

If you plan on having VIP ranks, know exactly what permissions, kits, or perks each rank should receive so we can build the groups accurately.
