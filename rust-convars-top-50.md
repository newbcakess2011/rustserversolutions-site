**⚙️ THE TOP 50 MOST COMMON RUST SERVER CONVARS ⚙️**

*There are over 900 console variables in Rust. Below are the top 50 most frequently requested settings by server owners. If you want any of these changed from their default values, just let us know in your ticket!*

**🌍 CORE SERVER SETTINGS**
1. `server.maxplayers` - Maximum number of players allowed.
2. `server.worldsize` - Size of the map (default 4500).
3. `server.seed` - The map generation seed.
4. `server.saveinterval` - Seconds between map saves (default 600).
5. `server.pve` - Enable native PvE mode (default false).
6. `server.radiation` - Enable/disable radiation globally (default true).
7. `server.globalchat` - Enable/disable global text chat (default true).
8. `server.censorplayerlist` - Hide player list from server queries (default false).
9. `server.idlekick` - Minutes before an AFK player is kicked (default 30).
10. `server.itemdespawn` - Seconds before dropped items despawn (default 300).
11. `server.corpsedespawn` - Seconds before player corpses despawn (default 300).
12. `server.woundingenabled` - Enable/disable the wounded state (default true).
13. `server.fallfalldamage` - Enable/disable fall damage (default true).

**🏚️ DECAY & UPKEEP**
14. `decay.scale` - Global multiplier for decay damage (default 1). *Set to 0 to disable.*
15. `decay.upkeep` - Enable/disable Tool Cupboard upkeep (default true).
16. `decay.upkeep_period_minutes` - Minutes of upkeep a full TC provides (default 1440).
17. `decay.delay_twig` - Hours before twig starts decaying (default 0).
18. `decay.delay_wood` - Hours before wood starts decaying (default 0).
19. `decay.delay_stone` - Hours before stone starts decaying (default 0).
20. `decay.delay_metal` - Hours before metal starts decaying (default 0).
21. `decay.delay_toptier` - Hours before armored starts decaying (default 0).
